ForPaper 安装说明（macOS）
================================

ForPaper 是一款基于 Zotero 构建的开源 AI 文献阅读工具。
本安装包完全独立运行 —— 不需要、也不会影响你电脑上已安装的 Zotero。

【系统要求】
- 任何 Mac：Apple 芯片（M 系列）和 Intel 芯片均原生支持
- 无需安装 Zotero 或任何其他软件

【安装步骤】
1. 把 ForPaper.app 拖到右边的 Applications（应用程序）快捷方式
2. 双击运行「双击修复.command」（仅首次需要一次）
   —— 因为 ForPaper 是开源免费软件，没有购买 Apple 开发者签名，
      直接打开会提示「已损坏」，修复脚本一键解除 macOS 的拦截
3. 从「应用程序」中打开 ForPaper，开始使用

  也可以不用脚本：在「终端」执行一行命令效果相同：
  xattr -cr /Applications/ForPaper.app

【首次使用：配置你自己的 AI 模型】
ForPaper 开源版不内置任何模型服务，AI 聊天使用你自己的 API：
1. 打开任意一篇 PDF，点击右侧「AI 聊天」面板
2. 点击输入框左下角的「自定义模型」→「管理自定义模型」
3. 点一下供应商按钮（DeepSeek / Kimi / 智谱 GLM / 阿里千问 / OpenAI /
   Gemini / Grok）——服务器地址和模型名称会自动填好
4. 只需再粘贴你的 API Key。可点「测试连接」验证配置是否正确，
   显示绿色「连接成功」后点「添加」即可开始对话
   （列表里没有的服务选「自定义」手动填地址即可，
    支持 OpenAI 兼容和 Anthropic 两种格式，含 OpenRouter、本地 Ollama 等）

【可选：AI 全文解析（MinerU 本地服务）】
「AI 解析 PDF / 全文总结」功能依赖本地 MinerU 服务。如需使用：
双击运行「一键部署AI解析.command」，全程自动完成（约 10-30 分钟，
主要时间花在下载约 2GB 解析模型），只需部署一次。
部署后开机自启、纯本地运行、数据不出本机，ForPaper 无需任何设置
即可直接使用（默认连接 127.0.0.1:8004）。
不部署也不影响其他所有功能（阅读、笔记、AI 聊天等）。

【数据说明】
- 文献数据默认存放在 ~/Zotero 目录（与 Zotero 相同）。
  如果你同时安装了 Zotero，两者不能同时运行（数据库互斥），
  关闭一个再开另一个即可。
- API Key 只保存在你自己的电脑上，不会上传到任何服务器。

开源地址：https://github.com/godfreya5/ForPaper
